# Environment Variables

Below is a table of the current environment variables for the project. Example values can be found inside of `.envrc.example`.

| Name                                      | Description                                                                  | Default      | Type   | Notes                                                                                                                                                                 |
|-------------------------------------------|------------------------------------------------------------------------------|--------------|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| NVIM_COLOR_SCHEME                         | Set the colour scheme used in the editor on startup.                         | "tokyonight" | string | In the case that the colour scheme cannot be applied, the default "tokyonight" theme is applied instead.                                                              |
| NVIM_DAP_HYDRA_ENABLED                    | Enable Hydra transient keymap menu for DAP debugging commands.               | N/A          | string | Set to "1" to enable. When enabled, `<Leader>d` opens a Hydra menu with single-letter shortcuts. When disabled, standard `<Leader>d*` keymaps are used.              |
| NVIM_DEBUG_CSHARP_BINARY                  | The name of the C# dll to use when debugging a .NET project.                 | N/A          | string | The dll must be inside of "/bin/Debug/net{version}/". Specify the name only, without the ".dll" extension. If unset, the user will be prompted to provide the full path manually when starting a debug session.                 |
| NVIM_DEBUG_CSHARP_VERSION                 | The target framework version of the .NET project being debugged.             | N/A          | string | Set to the version number only, e.g. "10.0". If set without NVIM_DEBUG_CSHARP_BINARY, the prompt will open inside the current directory. |
| NVIM_DEBUG_RUST_BINARY                    | The name of the Rust binary to use when debugging a Rust project.            | N/A          | string | The binary must be inside of "/target/debug". If this value is not set, the user will instead be prompted to manually provide the name when starting a debug session. |
| NVIM_PROJECT_CONFIG_NAME                  | The name of a lua module to load from "/lua/myconfig/projectconfigs".        | N/A          | string | The lua module must export a "setup" function in order to be loaded.                                                                                                  |
